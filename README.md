# concurrent-delay-map

Static site for the Concurrent Delay Map, served with GitHub Pages at https://gavacharles.github.io/concurrent-delay-map/

## Contents

| File | Purpose |
|---|---|
| `index.html` | The whole site: one self-contained page with two views (`#explorer`, `#case-law`). All CSS, JavaScript and data are inline; the only external resource is Google Fonts. |
| `og-image.png` | 1200×630 preview image used in link cards (Open Graph and Twitter tags in `index.html`). |
| `.nojekyll` | Tells GitHub Pages to serve the files as they are, without a Jekyll build. |

There is no build step, package manager or tracking in this repository.

## Running locally

Open `index.html` in a browser, or serve the folder:

```
python -m http.server 8000
```

Then visit http://localhost:8000.

## Updating

`index.html` and `og-image.png` are generated by `site/build_site.py` in [concurrent_delay_ml](https://github.com/gavacharles/concurrent_delay_ml), not edited here. To publish a new version, rebuild there, copy `site/dist/` into this folder, then commit and push to `main`. GitHub Pages redeploys automatically from the root of `main`.
