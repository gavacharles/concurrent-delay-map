# Concurrent Delay Map

An interactive map of concurrent delay in construction, live at **https://gavacharles.github.io/concurrent-delay-map/**

- **Explorer:** set up an employer delay and a contractor delay on a programme. Seven legal approaches then allocate the extension of time and the money: the English actual-delay test, as-planned impact, overlapping windows, Scottish apportionment (City Inn), strict sequence, NEC4 prospective assessment, and a Cyden-style exclusion clause. Presets reconstruct Malmaison, Adyard, Saga Cruises, Thomas Barnes, City Inn and Cyden.
- **Case law, 1999–2024:** how English and Scottish courts, the SCL Protocol and the standard forms have treated concurrent delay. Each entry is tagged with the rule it supports and how it was checked.

The page is a single static HTML file with no build step and no tracking. It is part of ongoing research, "One Schedule, Many Laws: doctrine-conditioned causal attribution and explainable AI for concurrent delay".

**Not legal advice.** The case presets are stylised two-path reconstructions. Entries marked "judgment read" were checked against the judgment text on the National Archives' Find Case Law service (November 2026). Other entries rely on later judgments that quote them, on secondary sources or on commentary, as marked. The contract always governs.
